# AI 算法学习路线（跟着 labuladong 走，Python + NumPy 从零手写）

和 LeetCode 刷题并行。主线跟着 labuladong.online「AI 开发」板块的 **《机器学习 & LLM 算法》** 目录顺序走，
每读完一组文章，就在这个仓库里用 NumPy 自己再写一遍。另一门 **《Agent 原理和开发》** 作为工程向的选修线。

> 本文件只记录目录结构和我们自己的练习设计，不摘抄站点的付费正文。具体讲解去站点上读。

## 怎么用这份路线

- **按关卡走，不按周走。** 有空就推进一关，忙的时候停下也没关系。"参考用时"只是让你心里有数。
- **每一小节的固定流程：**
  1. Claude 在你的 Chrome 里读对应文章（站点用 PyTorch 讲解，配有交互图和在线 Notebook），按你的水平用中文讲给你。
  2. 如果文章带配套练习题，Claude 把题意转述给你，先口头或在 PyTorch 里过一遍。
  3. 回到这个仓库，**只用 NumPy** 重写核心算法：先中文讲直觉 + 能手算的小例子，手推公式，关键一行自己写。
  4. 验收：数值梯度检查（`ai/common/gradcheck.py`）/ 和 PyTorch 对拍 / 小数据上 loss 下降。
  5. 一句话复盘：核心思想是什么，和哪道 LeetCode 结构相似。
- **PyTorch 只用来对拍**，不写主体。唯一例外是关卡 7（LLM 开发基础），那一关本来就是学怎么用现成的模型和工具。
- 目录约定：`ai/<关卡目录>/<练习>.py` 写实现，`test_<练习>.py` 写测试，在仓库根目录运行 `python -m pytest ai/`。
