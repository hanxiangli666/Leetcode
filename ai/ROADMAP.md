# AI 算法学习路线（从零手写，Python + NumPy）

和 LeetCode 刷题并行。目标不是"会调库"，而是每个核心算法都能**自己推导、自己写出来、自己验证对不对**。

## 怎么用这份路线

- **按关卡走，不按周走。** 有空就推进一关，忙的时候停下也没关系。每关后面的"参考用时"只是让你心里有数。
- **只用 NumPy 实现。** PyTorch 只用来对拍（比较结果），不用来写主体。
- **每个练习的流程**（和刷题一样）：
  1. 先用中文讲直觉，配一个能手算的小例子（比如 2×2 矩阵）。
  2. 手推公式，尤其是梯度。
  3. 写代码，最关键的一行（通常是梯度或更新式）自己写。
  4. 跑测试：数值梯度检查 / 和 PyTorch 对拍 / 在小数据上 loss 下降。
  5. 一句话复盘：这个算法的核心思想是什么，和哪道 LeetCode 有相似的结构。
- **验收标准**写在每个练习后面，测试全部通过才算过关。
- 目录约定：`ai/<关卡>/<练习>.py` 写实现，`ai/<关卡>/test_<练习>.py` 写测试，运行 `pytest ai/`。

## 关卡 0：工具与数学热身

**为什么先做这个：** 后面每一关都要算梯度，梯度写错是最常见的 bug。先造一个"梯度裁判"，以后所有梯度都交给它验证。

| # | 练习 | 要点 | 验收 |
| --- | --- | --- | --- |
| 0.1 | NumPy 向量化 | broadcasting、`axis`、`keepdims`；把双重 for 循环的欧氏距离矩阵改写成无循环版本 | 和循环版结果一致，速度快 50 倍以上 |
| 0.2 | 数值梯度 `numerical_grad` | 中心差分 `(f(x+h) - f(x-h)) / 2h`，对多维数组逐元素扰动 | 对 `sum(x**2)`、`sum(sin(x))` 误差 < 1e-6 |
| 0.3 | 梯度检查 `grad_check` | 相对误差 `|a-b| / max(|a|,|b|)` | 能抓出一个故意写错的梯度 |
| 0.4 | 矩阵求导手推 | `y = Wx + b`、`L = ||Wx - y||²` 对 W、b 的梯度，先用 2×2 手算再写成矩阵形式 | 用 0.3 验证通过 |
| 0.5 | 数值稳定的 softmax / log-sum-exp | 减去最大值，避免溢出 | 输入 `[1000, 1001]` 不出 nan |

**配套 LeetCode：** 303 区域和检索、304 二维区域和检索、238 除自身以外数组的乘积（已做，可复习）、48 旋转图像。

> 已备好骨架：`ai/common/gradcheck.py` 和测试，关键行留给你写。

## 关卡 1：经典机器学习

**核心思想：** 机器学习 = 定义模型 + 定义损失 + 用梯度下降最小化损失。这一关把这套"三件套"练熟。

| # | 练习 | 要点 | 验收 |
| --- | --- | --- | --- |
| 1.1 | 线性回归（闭式解） | 正规方程 `w = (XᵀX)⁻¹Xᵀy`，用 `np.linalg.solve` 而不是求逆 | 和 `np.linalg.lstsq` 结果一致 |
| 1.2 | 线性回归（梯度下降） | 手推 MSE 梯度，批量梯度下降，学习率太大/太小各试一次 | 收敛到 1.1 的解，误差 < 1e-4 |
| 1.3 | 逻辑回归 | sigmoid + 二元交叉熵，梯度化简为 `Xᵀ(p - y) / n` | 梯度检查通过；在可分数据上准确率 > 95% |
| 1.4 | Softmax 回归 | 多分类交叉熵，梯度 `p - onehot(y)` | 梯度检查通过；和 PyTorch `cross_entropy` 对拍 |
| 1.5 | 正则化 | L2（权重衰减）、L1，画出不同 λ 下的权重大小 | 能解释为什么 L1 产生稀疏解 |
| 1.6 | kNN | 向量化距离矩阵 + `np.argpartition` 取 Top-K | 和暴力排序结果一致 |
| 1.7 | k-means | 分配-更新两步交替；k-means++ 初始化 | loss 单调不增；在 3 簇数据上找对中心 |
| 1.8 | PCA | 中心化 + SVD，解释方差比 | 重建误差随主成分数单调下降 |

**配套 LeetCode：** 215 数组中的第 K 个最大元素、347 前 K 个高频元素、973 最接近原点的 K 个点（就是 kNN 的核心）、35/34 二分查找边界。

## 关卡 2：优化器

**核心思想：** 梯度只告诉你方向，优化器决定"每一步走多远、要不要带惯性"。

| # | 练习 | 要点 | 验收 |
| --- | --- | --- | --- |
| 2.1 | SGD 与 mini-batch | 每轮打乱数据，按 batch 更新 | 在 1.3 的数据上收敛 |
| 2.2 | Momentum / Nesterov | 速度项 `v = βv + g` | 在狭长山谷函数上比 SGD 快 |
| 2.3 | RMSProp | 按维度缩放学习率 | — |
| 2.4 | Adam | 一阶 + 二阶矩，偏差修正 | 和 `torch.optim.Adam` 逐步对拍，10 步内误差 < 1e-6 |
| 2.5 | 学习率调度 | step decay、cosine、warmup | 画出学习率曲线 |
| 2.6 | 可视化对比 | 在 Rosenbrock 函数 `(1-x)² + 100(y-x²)²` 上画四种优化器的轨迹 | 一张图，配三句话结论 |

**统一接口：** 所有优化器都实现 `step(params, grads)`，关卡 3 之后直接复用。

## 关卡 3：反向传播与自动微分

**核心思想：** 反向传播 = 在计算图上按**拓扑序的逆序**应用链式法则。这正好是图论里的拓扑排序。

| # | 练习 | 要点 | 验收 |
| --- | --- | --- | --- |
| 3.1 | 标量 autograd `Value` | 支持 `+ - * / ** exp log tanh relu`，每个节点记住父节点和局部梯度 | 对任意表达式，梯度和数值梯度一致 |
| 3.2 | `backward()` | DFS 拓扑排序，逆序累加梯度（注意同一节点被用多次时梯度要**累加**） | `a*a + a` 的梯度正确 |
| 3.3 | 用 `Value` 搭 MLP | 神经元 → 层 → 网络，在月牙形二分类数据上训练 | 准确率 > 95% |
| 3.4 | 张量版层 | `Linear`、`ReLU`、`Sigmoid`、`SoftmaxCrossEntropy`，每层写 `forward` / `backward` | 每层单独过梯度检查 |
| 3.5 | 初始化 | Xavier / He 初始化，对比全零初始化为什么学不动 | 能解释对称性问题 |
| 3.6 | MNIST 上的 MLP | 两层 MLP + 关卡 2 的 Adam | 测试集准确率 > 97% |

**配套 LeetCode：** 207 课程表、210 课程表 II（拓扑排序本身）、133 克隆图、797 所有可能的路径。

## 关卡 5：注意力与 Transformer

**核心思想：** 注意力 = 用 query 和每个 key 算相似度，softmax 成权重，再对 value 加权平均。Transformer 就是把它和 MLP、残差、归一化堆起来。

| # | 练习 | 要点 | 验收 |
| --- | --- | --- | --- |
| 5.1 | 缩放点积注意力 | `softmax(QKᵀ / √d) V`，解释为什么要除以 √d | 和 PyTorch `scaled_dot_product_attention` 对拍 |
| 5.2 | Mask | padding mask 和因果（下三角）mask | 未来位置的权重恰好为 0 |
| 5.3 | 注意力的 backward | 手推 softmax 的雅可比，写出完整反向 | 梯度检查通过 |
| 5.4 | 多头注意力 | reshape 拆头、拼回，输出投影 | 和 PyTorch `MultiheadAttention` 对拍 |
| 5.5 | 位置编码 | 正弦位置编码；了解 RoPE 的思路 | 画出编码热力图 |
| 5.6 | Transformer Block | Pre-LN：`x + Attn(LN(x))`，`x + MLP(LN(x))`，GELU | 整块梯度检查通过 |
| 5.7 | 字符级 mini-GPT | 在一段中文或英文小说上训练，自己写训练循环 | loss 明显下降，能生成像样的文本 |
| 5.8 | 采样策略 | greedy、temperature、top-k、top-p | 能解释 temperature 对分布的影响 |
| 5.9 | KV cache | 生成时缓存过去的 K、V，只算新 token | 和不带缓存的输出完全一致，且更快 |

**配套 LeetCode：** 739 每日温度、84 柱状图中最大的矩形（单调栈）、692 前 K 个高频单词（采样里的 top-k）、560 和为 K 的子数组（前缀和）。
